# Tip Calculator (CLI)

A simple command-line Tip Calculator built in Python.

This project calculates:
- Tip amount
- Total bill
- Amount per person

It includes:
- Input validation
- Error handling
- Protection against invalid and negative inputs

---

## How to Run

Make sure Python is installed.

Run:

python main.py

---

## Features

- Handles non-numeric input
- Prevents division by zero
- Prevents negative values
- Formats currency to 2 decimal places
